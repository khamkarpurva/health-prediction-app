# Health Prediction Application

## Overview

A Flask-based healthcare application that allows users to manage patient records and generate AI-based health prediction remarks.

## Features

* Add Patient
* View Patients
* Edit Patient
* Delete Patient
* SQLite Database
* AI Health Prediction
* Input Validation
* Bootstrap User Interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* Bootstrap

## Health Parameters

* Glucose
* Haemoglobin
* Cholesterol

## Prediction Logic

The application analyzes patient health metrics and generates remarks such as:

* High risk of diabetes and cardiovascular disease
* Possible anemia detected
* High cholesterol level detected
* Health indicators appear normal

## How to Run

Install Flask:

pip install flask

Run:

python app.py

Open:

http://127.0.0.1:5000
